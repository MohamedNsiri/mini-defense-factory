Q0.1:

- CVE (Common Vulnerabilities and Exposures) : identifiant unique attribué à une vulnérabilité informatique connue.

- CVSS (Common Vulnerability Scoring System) : Score qui évalue la gravité technique d’une vulnérabilité, généralement de 0 à 10.

- EPSS (Exploit Prediction Scoring System) : Score qui estime la probabilité qu’une vulnérabilité soit exploitée dans les 30 prochains jours.

- Catalogue CISA KEV (Known Exploited Vulnerabilities) : Catalogue des vulnérabilités dont l’exploitation réelle est connue et confirmée par la CISA.

Q0.2:

- Exposé : un service est accessible depuis un réseau ou un attaquant peut l’atteindre.

- Exploitable : un attaquant peut effectivement tirer parti d’une vulnérabilité pour provoquer un effet malveillant.

Exemple : un serveur SSH contient une version vulnérable, mais il est accessible uniquement depuis un réseau interne isolé, il est donc vulnérable, mais pas exposé à l'internet.
